AtmoSync – Micro-Climate Analytics Dashboard

1. Dashboard Overview

The AtmoSync dashboard will monitor and analyze micro-climate conditions using sensor data.

2. Temperature Monitoring

- Display temperature readings from sensors.
- Visualize temperature changes over time.
- Chart Type: Line Chart.

3. Humidity Monitoring

- Display humidity readings from sensors.
- Analyze humidity trends over time.
- Chart Type: Line Chart.

4. Location-wise Comparison

- Compare temperature across different locations.
- Compare humidity levels across locations.
- Chart Type: Bar Chart.

5. Sensor Data Overview

Display the available sensor information in a table.

Suggested columns:

- Sensor ID
- Location
- Temperature
- Humidity
- Timestamp

Chart Type: Table.

6. Dashboard Components

- Temperature Trend
- Humidity Trend
- Location Comparison
- Sensor Data Table

7. Technology

- Apache Superset
- Snowflake
- SQL
- Python

8. Dashboard Objective

To provide a clear visual representation of micro-climate data and help users monitor environmental conditions across different locations.

Note

Actual charts and sensor readings will be connected after the project data becomes available in Snowflake.
